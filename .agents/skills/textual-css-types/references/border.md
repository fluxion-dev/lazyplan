# <border>

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/css_types/border/

Border edge, line style, and colour shorthand.

## Grammar

`edge | style | colour, or a combination`

## Consumers

border, outline.

## Example

```css
border: solid $primary;
```
