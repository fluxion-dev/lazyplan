# <color>

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/css_types/color/

A named theme colour, hex colour, rgb(), hsl(), or $variable.

## Grammar

`name | #rrggbb | #rrggbbaa | rgb(...) | hsl(...) | $variable`

## Consumers

color, background, border, outline, tint, scrollbar-*.

## Example

```css
color: $text-muted;
```
