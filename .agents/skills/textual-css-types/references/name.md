# <name>

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/css_types/name/

An identifier used for layers, ids, and classes.

## Grammar

`[a-zA-Z_-][a-zA-Z0-9_-]*`

## Consumers

layer, layers, class names.

## Example

```css
layer: overlay;
```
