# <percentage>

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/css_types/percentage/

A percentage of the containing dimension.

## Grammar

`[0-9]+%`

## Consumers

width, height, offset, margin, padding.

## Example

```css
width: 50%;
```
