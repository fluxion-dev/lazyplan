# <scalar>

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/css_types/scalar/

A cell count, fraction, percentage, or auto keyword.

## Grammar

`integer | numberfr | percentage | auto`

## Consumers

width, height, min/max, margin, padding, offset.

## Example

```css
height: 1fr;
```
