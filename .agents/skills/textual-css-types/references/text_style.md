# <text-style>

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/css_types/text_style/

One or more text decorations.

## Grammar

`bold | italic | underline | reverse | strike | none, combinable`

## Consumers

text-style, link-style, border-title-style.

## Example

```css
text-style: bold underline;
```
