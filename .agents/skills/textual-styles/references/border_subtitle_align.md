# border-subtitle-align

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/border_subtitle_align/

Horizontal alignment of the border subtitle.

## Values

`left|center|right`

## Default and inheritance

Default: right. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with a border subtitle.

## Example

```css
border-subtitle-align: inherit;
```
