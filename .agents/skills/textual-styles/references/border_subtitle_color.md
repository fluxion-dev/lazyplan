# border-subtitle-color

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/border_subtitle_color/

Text colour of the border subtitle.

## Values

`colour`

## Default and inheritance

Default: theme foreground. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with a border subtitle.

## Example

```css
border-subtitle-color: $primary;
```
