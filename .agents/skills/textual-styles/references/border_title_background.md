# border-title-background

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/border_title_background/

Background colour behind the border title.

## Values

`colour`

## Default and inheritance

Default: transparent. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with a border title.

## Example

```css
border-title-background: $primary;
```
