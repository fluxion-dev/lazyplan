# box-sizing

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/box_sizing/

Whether width and height include padding and border.

## Values

`border-box|content-box`

## Default and inheritance

Default: border-box. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
box-sizing: inherit;
```
