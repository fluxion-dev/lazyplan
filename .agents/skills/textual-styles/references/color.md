# color

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/color/

Foreground text colour.

## Values

`colour`

## Default and inheritance

Default: theme foreground. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets with text.

## Example

```css
color: $primary;
```
