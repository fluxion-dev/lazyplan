# content-align

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/content_align/

Alignment of content inside the widget's content box.

## Values

`horizontal vertical pair`

## Default and inheritance

Default: left top. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with content.

## Example

```css
content-align: 1 2;
```
