# display

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/display/

Whether the widget participates in layout.

## Values

`block|none`

## Default and inheritance

Default: block. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
display: inherit;
```
