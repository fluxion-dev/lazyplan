# Grid

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/grid/

Group entry for the grid layout properties.

## Values

`see grid-columns, grid-rows, grid-gutter, grid-size`

## Default and inheritance

Default: n/a. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

layout: grid containers.

## Example

```css
Grid: inherit;
```
