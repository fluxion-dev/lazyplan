# grid-columns

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/grid/grid_columns/

Column tracks for a grid container.

## Values

`space-separated track sizes`

## Default and inheritance

Default: 1fr. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

layout: grid containers.

## Example

```css
grid-columns: 1fr 2fr;
```
