# grid-gutter

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/grid/grid_gutter/

Shorthand for horizontal and vertical grid gaps.

## Values

`horizontal vertical`

## Default and inheritance

Default: 0. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

grid containers.

## Example

```css
grid-gutter: 1 2;
```

## Related

- `grid-rows, grid-columns`
