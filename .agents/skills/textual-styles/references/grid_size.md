# grid-size

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/grid/grid_size/

Convenience shorthand for a uniform grid's columns and rows.

## Values

`columns rows`

## Default and inheritance

Default: auto. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

grid containers.

## Example

```css
grid-size: inherit;
```

## Related

- `grid-rows, grid-columns`
