# link-color

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/links/link_color/

Colour of link text.

## Values

`colour`

## Default and inheritance

Default: theme link colour. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with links.

## Example

```css
link-color: $primary;
```
