# link-style

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/links/link_style/

Text style for links.

## Values

`underline or combinations`

## Default and inheritance

Default: underline. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with links.

## Example

```css
link-style: inherit;
```
