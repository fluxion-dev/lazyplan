# Links

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/links/

Group entry for link colour, background, and style properties.

## Values

`see link-* properties`

## Default and inheritance

Default: theme link colours. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with links.

## Example

```css
Links: inherit;
```

## Related

- `link-color, link-background, link-style`
