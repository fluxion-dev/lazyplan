# margin

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/margin/

Space outside the widget's border.

## Values

`one to four scalars`

## Default and inheritance

Default: 0. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
margin: 1;
```

## Related

- `padding, offset`
