# offset

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/offset/

Visual offset without changing layout space.

## Values

`horizontal vertical scalars`

## Default and inheritance

Default: 0 0. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
offset: 1 2;
```

- `margin, position`
