# opacity

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/opacity/

Overall opacity of the widget, including children.

## Values

`0-1`

## Default and inheritance

Default: 1. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
opacity: 0.8;
```
