# outline

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/outline/

A line drawn outside the border without affecting layout.

## Values

`edge, style, colour`

## Default and inheritance

Default: none. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
outline: solid $primary;
```

## Related

- `border, keyline`
