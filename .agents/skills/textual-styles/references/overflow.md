# overflow

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/overflow/

How content that exceeds the box is handled.

## Values

`hidden|scroll|auto`

## Default and inheritance

Default: hidden. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
overflow: inherit;
```
