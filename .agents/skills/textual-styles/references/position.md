# position

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/position/

Normal flow or absolute positioning.

## Values

`relative|absolute`

## Default and inheritance

Default: relative. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
position: inherit;
```
