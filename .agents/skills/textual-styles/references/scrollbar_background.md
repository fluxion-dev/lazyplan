# scrollbar-background

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/scrollbar_colors/scrollbar_background/

Scrollbar track background.

## Values

`colour`

## Default and inheritance

Default: theme. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

scrollable widgets.

## Example

```css
scrollbar-background: $primary;
```
