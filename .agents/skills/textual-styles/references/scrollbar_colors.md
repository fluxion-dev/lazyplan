# Scrollbar colors

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/scrollbar_colors/

Group entry for scrollbar track and thumb colours.

## Values

`see scrollbar-* properties`

## Default and inheritance

Default: theme scrollbar colours. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

scrollable widgets.

## Example

```css
Scrollbar colors: inherit;
```

## Related

- `scrollbar-background, scrollbar-color`
