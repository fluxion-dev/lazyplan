# scrollbar-size

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/scrollbar_size/

Scrollbar thickness.

## Values

`horizontal vertical cells`

## Default and inheritance

Default: 1 2. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

scrollable widgets.

## Example

```css
scrollbar-size: 1 2;
```
