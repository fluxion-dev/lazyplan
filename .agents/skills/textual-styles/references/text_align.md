# text-align

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/text_align/

Horizontal alignment of text inside its lines.

## Values

`left|center|right|justify`

## Default and inheritance

Default: left. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with text.

## Example

```css
text-align: inherit;
```
