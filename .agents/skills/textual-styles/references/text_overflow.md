# text-overflow

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/text_overflow/

How overflowing single-line text is clipped.

## Values

`clip|ellipsis|fold`

## Default and inheritance

Default: clip. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with text.

## Example

```css
text-overflow: inherit;
```
