# text-wrap

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/text_wrap/

How text wraps at line ends.

## Values

`wrap|nowrap`

## Default and inheritance

Default: wrap. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

widgets with text.

## Example

```css
text-wrap: inherit;
```
