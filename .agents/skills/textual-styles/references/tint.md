# tint

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/tint/

Blends the widget towards a colour.

## Values

`colour and percentage`

## Default and inheritance

Default: transparent 0%. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
tint: inherit;
```
