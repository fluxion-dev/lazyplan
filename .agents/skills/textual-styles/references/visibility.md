# visibility

**Textual:** 8.2.8
**Official:** https://textual.textualize.io/styles/visibility/

Hides the widget while keeping its layout space.

## Values

`visible|hidden`

## Default and inheritance

Default: visible. Textual resolves the final value from the widget, its
classes, the app CSS, and the active theme. Use `styles.get_rule()` or the
devtools CSS inspector when the cascade is unclear.

## Applies to

all widgets.

## Example

```css
visibility: inherit;
```
