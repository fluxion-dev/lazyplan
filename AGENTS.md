# Agent instructions

## Documentation

Human documentation is limited to what a reader cannot get from the tool
itself:

- `README.md` — what lazyplan is, install, first run, why it differs, next links.
- `CONTRIBUTING.md` — dev setup, gates, PR rules, release pointer.
- `docs/usage.md` — the single usage guide.

`CHANGELOG.md` records history. `docs/lpui.1` and `docs/lazyplan.1` are
generated by `tools/gen-man.py`; never hand-edit or duplicate them. Packaged
agent docs under `src/lazyplan/data/` ship with the product.

Do not restate source, `--help`, the man pages, tests, or release automation.
Derive internals from the code. If a sentence does not help a human install,
run, or contribute to lazyplan, do not write it, and delete it when you find
it. `tools/check-docs.py` enforces this allowlist and the relative links in
the retained files.
