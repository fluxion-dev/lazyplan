pipx install lazyplan-tui

On Windows: pipx install --backend pip lazyplan-tui

FAQ

Questions, answered.

What is lazyplan?

A terminal plan for you and your coding agent. Plans, milestones, tasks, and acceptance criteria live in one place, so the work stays visible instead of disappearing into chat.

Who is it for?

Developers and small teams who use coding agents and want one plan everyone can see.

Does it work with my coding agent?

Yes. It works with OpenCode, Claude Code, Cursor, Codex, Gemini CLI, and any agent that can run a command.

Does it run on Windows, macOS, and Linux?

Yes. It runs on Linux, macOS, and Windows, and your plan stays local on your machine.

Where is my data stored?

In a local SQLite database on your machine. There is no account and no cloud dependency, and you can export or back up everything at any time.

Can I use one agent to plan and another to execute?

Yes. A planner agent can write the plan while an executor or subagent claims and completes individual tasks. You can change roles, run both at once, or do the work yourself; everyone reads the same plan.
