How this review works

Every screen and state in lpui is captured from the real Textual app with deterministic fixtures. The list on the left is the full surface area, grouped by where the screen lives.

Leave feedback

  • Pick a verdict: approve, concern, idea, or question.
  • Concerns and ideas take a severity and optional tags.
  • One screen can hold several entries. The newest entry drives the sidebar dot, but every entry is kept.

Where it goes

Static hosting keeps feedback in this browser. Run python tools/ux-review-server.py after a build to save every submission to .agents/ux-review/feedback.json instead. Export and import work in both modes.

Roll it into a plan

The UX plan view turns every open concern, idea, and question into a plan apply document: one milestone per screen group, one task per review entry, plus acceptance criteria. Download the JSON and run the printed command; retries are idempotent because every key is stable.
